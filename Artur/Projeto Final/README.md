## Sobre o projeto

Este portfólio foi desenvolvido com o objetivo de apresentar
os conhecimentos adquiridos durante a disciplina de
Desenvolvimento de Interfaces.

O site possui uma apresentação pessoal, informações sobre
minhas habilidades, projetos acadêmicos e pessoais, além
de um formulário de contato.

## Projetos apresentados

### 1. Interestelar

Página responsiva sobre o filme Interestelar, apresentando
sinopse, elenco e ficha técnica.

Tecnologias: HTML, CSS, Flexbox e Grid.

### 2. Stranger Things

Página sobre a série Stranger Things, apresentando sua
história, personagens, galeria e informações da série.

Tecnologias: HTML, CSS e Bootstrap.

### 3. PortfolioHUB

Projeto acadêmico voltado à organização e publicação de
trabalhos, utilizando controle de versões.

Tecnologias: Git, GitHub e HTML.

### 4. Lista de Tarefas (To-do)

Atividade baseada no exemplo apresentado em aula,
com personalização da interface.

Permite adicionar, concluir e excluir tarefas, mantendo
os dados armazenados no navegador.

Tecnologias: HTML, CSS, Bootstrap, JavaScript e LocalStorage.

### 5. Garage Palio

Projeto pessoal sobre meu Fiat Palio Fire 1.0 2008.

Apresenta informações do veículo, propostas de personalização
e um checklist interativo com barra de progresso.

Tecnologias: HTML, CSS, Bootstrap, JavaScript e LocalStorage.

## Como executar

1. Baixar os arquivos do projeto.
2. Manter a estrutura original das pastas.
3. Acessar a pasta Artur/Projeto Final.
4. Abrir o arquivo index.html no navegador.
5. Navegar pelas seções e acessar os projetos.

Uma conexão com a internet é necessária para carregar
as bibliotecas externas utilizadas pelo site.
