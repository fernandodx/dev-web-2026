# Projeto de Design System 



1°) Foram escolhidas as paletas de cores Primary, Secundary, Tertiary, Background, OnBackground e OnSurface tanto para o modo light como para o dark.

2°) Foram escolhidas as tipografias para o Headline, Subtitle, Body, Button e Title.

3°) Tanto as cores como a tipografia foram transformadas em variáveis.
4°) Foram feitos os botões Default, Outilne, Loading com layout vertical como horizontal.
5°) Foi feita a Appbar tanto light como dark .

6°) Foram transformados em componentes as cores, tipografia e botões.

7°) Foram feitas as telas de perfil, menu, histórico, recentes, perfil, configuração, transição e configuração no modo dark.
