\# Design System - Aplicativo Meus Treinos





\## Cores



O Design System possui as seguintes cores semânticas:



\- Primary

\- Secondary

\- Tertiary

\- Background

\- OnBackground

\- OnSurface



As cores foram organizadas para os modos Light e Dark.





\## Tipografia



A tipografia do projeto utiliza a família Roboto e contém os seguintes estilos:



\- Headline

\- Title

\- Subtitle

\- Body

\- Button





\## Componentes



O Design System contém os seguintes componentes reutilizáveis:



\- Botão Primário

\- Botão Secundário

\- Botão Terciário

\- AppBar



A AppBar possui variações para os modos Light e Dark.
