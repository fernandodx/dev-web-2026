# 🎨 Projeto Design System & Protótipo Navegável

Este repositório contém a entrega da **1ª Avaliação Oficial** da disciplina, composta por um **Design System** estruturado e um **Protótipo Interativo Navegável** desenvolvido no Figma[cite: 1, 2].

---

## 📌 Descrição do Projeto

O objetivo deste projeto foi construir a estrutura básica de design e navegação para um aplicativo móvel[cite: 1, 3]. Foi desenvolvido um conjunto de variáveis globais de design, componentes reutilizáveis e um fluxo de telas interativo consumindo todos os elementos padronizados do Design System[cite: 1, 2].

---

## 🛠️ Conteúdo do Design System

1. **Variáveis de Cores (Light & Dark):**
   * `Primary`, `Secondary`, `Tertiary`, `Background`, `OnBackground` e a nova cor `onSurface`[cite: 1, 2].
2. **Tipografia:**
   * Estilos definidos para `Headline`, `Subtitle`, `Body`, `Button` e a nova fonte `Title`[cite: 1, 2].
3. **Componentes:**
   * Botões Primário, Secundário e Terciário com estados/estilos[cite: 1].
   * Componente `AppBar` com variante no modo **Dark**[cite: 1, 2].
4. **Protótipo Navegável:**
   * Fluxo interativo composto por 3 telas interconectadas consumindo todos os componentes e variáveis criados[cite: 1, 3].
