# 2ª Avaliação Oficial — Página de Filme (Interestelar)

Página web desenvolvida sobre o filme **Interestelar (2014)** aplicando os conceitos de HTML semântico e CSS puro (sem frameworks)[cite: 1].

## Estrutura do Projeto
* `index.html`: Estrutura semântica utilizando `<header>`, `<nav>`, `<main>`, `<section>`, `<article>` e `<footer>`[cite: 1].
* `estilo.css`: Estilização externa utilizando variáveis CSS no `:root` para controle de cores, fontes e espaçamentos, além de Flexbox e CSS Grid para layout responsivo[cite: 1].
