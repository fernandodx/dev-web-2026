# 3ª Avaliação Oficial — Página de Série (The Last of Us)

Página web responsiva desenvolvida sobre a série **The Last of Us** utilizando HTML semântico e o framework Bootstrap 5 via CDN[cite: 2].

## Componentes Implementados
* **HTML Semântico:** Uso de `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>` e `<footer>`[cite: 2].
* **Breadcrumb:** Navegação hierárquica de contexto no topo da página[cite: 2].
* **Carousel:** Carrossel interativo com 3 slides sobre a série[cite: 2].
* **Cards & Grid Responsivo:** Exibição do elenco principal e episódios em destaque organizados com o sistema de grid do Bootstrap[cite: 2].
