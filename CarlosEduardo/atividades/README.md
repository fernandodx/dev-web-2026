# dev-web-2026

Descrição do Projeto

O projeto foi desenvolvido por mim como parte da primeira avaliação oficial da disciplina, que pedia a criação de um Design System estruturado e um protótipo navegável no Figma.

Para as cores, eu organizei uma coleção de variáveis reutilizáveis contemplando Primary, Secondary, Tertiary, Background e OnBackground, além da nova cor solicitada, OnSurface, todas com valores definidos tanto para o modo Light quanto para o modo Dark.

Na tipografia, foram definidos os estilos Headline, Subtitle, Body e Button, com a adição do novo estilo Title, cada um configurado com tamanho, peso e espaçamento próprios, mantendo consistência com o restante do sistema.

Quanto aos componentes, o aluno criou os botões Primário, Secundário e Terciário como componentes reais do Figma não apenas elementos visuais soltos, reunidos em um único conjunto de variantes. Também foi criado o novo componente AppBar, contendo uma variante Dark, para servir como cabeçalho padrão das telas.

Por fim, essas variáveis e componentes foram aplicados no fluxo navegável do protótipo, com a AppBar presente em todas as telas e os botões utilizando as instâncias do componente criado, seguindo os nomes e padrões ensinados em aula.
