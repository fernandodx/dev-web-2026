# Página de Série: O Polígamo (2026)

Projeto desenvolvido com **HTML5 semântico** e **Bootstrap 5 (via CDN)** apresentando a série dramática *O Polígamo* (Netflix).

## Componentes Bootstrap Implementados

- **Breadcrumb:** Navegação estrutural no topo da página (`Início > Séries de Drama > O Polígamo (2026)`).
- **Carousel:** Galeria interativa com imagens e destaques da série.
- **Cards:** Seção responsiva em grid apresentando os personagens principais e seus conflitos.

## Estrutura do Repositório

- `index.html`: Página principal com tags semânticas (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`) e Bootstrap 5.
- `capa.png`, `cena1.jpg`, `cena2.jpg`, `elenco1.jpg`, `elenco2.jpg`: Imagens da série utilizadas no carrossel e nos cards.
- `README.md`: Documentação do projeto.
