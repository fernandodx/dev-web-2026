## 📌 Sobre o Projeto

O **dev-web-2026** é um projeto desenvolvido para a disciplina de Desenvolvimento Web, com o objetivo de aplicar conceitos de design de interfaces, identidade visual e criação de telas para um produto digital.

Por trabalhar na **GOL Linhas Aéreas**, utilizei minha experiência profissional como referência para desenvolver uma proposta visual relacionada ao setor aéreo e à logística.

O projeto recebeu o nome **LOG**, uma referência à palavra GOL escrita ao contrário, representando a inspiração para a criação da identidade da marca.

> 💡 A proposta é explorar uma identidade visual própria, utilizando referências do setor aéreo e elementos de design inspirados na GOL.

---

## 🎯 Objetivos

- Desenvolver uma identidade visual para o projeto.
- Criar uma proposta de produto digital relacionado à área de atuação profissional.
- Aplicar conceitos de design de interfaces (UI).
- Organizar e desenvolver telas com base em referências visuais.
- Integrar conhecimentos apresentados em aula com ideias próprias.
- Utilizar o Figma para prototipação e planejamento das interfaces.

---

## 🎨 Identidade Visual

### 🏷️ Nome da Marca

**LOG**

O nome foi escolhido como uma referência à marca GOL, utilizando a inversão da palavra como parte da proposta criativa do projeto.

### 🎨 Cores

A paleta de cores foi desenvolvida com inspiração nas cores utilizadas pela GOL Linhas Aéreas, buscando uma identidade visual relacionada ao setor aéreo.

> As cores foram adaptadas como referência para a proposta acadêmica do projeto.

### 🔤 Tipografia

A escolha da tipografia foi realizada de forma exploratória, utilizando um site de fontes e tipografias como referência.

O objetivo foi encontrar uma fonte que combinasse com a proposta visual da marca e com a organização das interfaces.

---

## 🧩 Componentes

Os componentes utilizados no projeto foram desenvolvidos a partir de uma combinação entre:

- Componentes apresentados nos exemplos do professor.
- Componentes adaptados para a proposta do projeto.
- Elementos criados de acordo com as necessidades das telas.

Essa combinação permitiu aplicar os conhecimentos desenvolvidos em aula, juntamente com ideias próprias de organização e apresentação visual.

---

## 🖥️ Telas do Projeto

As telas foram desenvolvidas utilizando referências da minha experiência profissional na GOL Linhas Aéreas.

A proposta busca representar elementos relacionados ao setor aéreo, à logística e à organização de processos, adaptando essas referências para a construção do produto acadêmico.

### Principais referências

- ✈️ Setor aéreo e operações.
- 📦 Logística e organização.
- 🎨 Identidade visual inspirada na GOL.
- 🖥️ Interface e experiência do usuário.
