# Página de Filme: Intocáveis (2011)

Projeto desenvolvido para a **2ª Avaliação Oficial** utilizando HTML5 semântico e CSS3 puro.

## Estrutura do Projeto

- `index.html`: Estrutura semântica completa da página (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`).
- `estilo.css`: Estilização da página com variáveis CSS definidas no `:root`, layout em Flexbox e CSS Grid, além de responsividade.

## Conteúdo Apresentado

- Título original e em português do filme (*Intouchables* / *Intocáveis*)
- Pôster oficial (referenciado por URL externa)
- Sinopse completa
- Ficha técnica com direção (Olivier Nakache e Éric Toledano)
- Elenco principal
