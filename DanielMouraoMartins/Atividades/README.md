\# 📚 Design System \& Protótipo — App de Estudos



\## 📌 Sobre o projeto



Este projeto foi desenvolvido como parte da \*\*1ª Avaliação — Design System \& Protótipo\*\*, utilizando o \*\*Figma\*\*.



O objetivo é criar um Design System estruturado com variáveis reutilizáveis, componentes e um protótipo navegável, seguindo padrões de organização visual, tipografia, cores e componentes de interface.



\---



\## 🎨 Design System



\### Cores



O Design System possui uma paleta organizada para os modos \*\*Light\*\* e \*\*Dark\*\*.



As seguintes variáveis de cor foram utilizadas:



\* \*\*Primary\*\* — Cor principal da interface.

\* \*\*Secondary\*\* — Cor secundária utilizada para elementos de apoio.

\* \*\*Tertiary\*\* — Cor terciária para destaques.

\* \*\*Background\*\* — Cor de fundo das telas.

\* \*\*OnBackground\*\* — Cor utilizada em elementos sobre o Background.

\* \*\*OnSurface\*\* — Cor utilizada sobre superfícies, com versões para \*\*Light\*\* e \*\*Dark\*\*.



As cores foram criadas como \*\*variáveis locais no Figma\*\*, permitindo sua reutilização em diferentes telas e componentes.



\---



\## ✏️ Tipografia



O sistema tipográfico foi estruturado com variáveis para manter a padronização visual.



Foram utilizadas as seguintes categorias:



\* \*\*Headline\*\* — Títulos principais.

\* \*\*Title\*\* — Títulos de seções e elementos de destaque.

\* \*\*Subtitle\*\* — Subtítulos e informações secundárias.

\* \*\*Body\*\* — Textos e conteúdos gerais.

\* \*\*Button\*\* — Textos utilizados nos botões.



Cada estilo possui especificações de \*\*tamanho, peso e espaçamento\*\*, garantindo consistência entre as telas do protótipo.



\---



\## 🧩 Componentes



O Design System possui os seguintes componentes:



\### Botão Primário



Utilizado para as principais ações da interface.



\### Botão Secundário



Utilizado para ações complementares.



\### Botão Terciário



Utilizado para ações de menor destaque.



\### AppBar



Componente utilizado na navegação e identificação das telas.



O AppBar possui duas variantes:



\* \*\*Light\*\*

\* \*\*Dark\*\*



Todos os componentes foram criados como \*\*componentes reais no Figma\*\*, permitindo sua reutilização durante a construção do protótipo.



\---



\## 📱 Protótipo



O protótipo representa um aplicativo de estudos com telas navegáveis.



As telas utilizam os componentes e variáveis criados no Design System, incluindo a \*\*AppBar\*\*, botões, cores e estilos tipográficos.



\### Fluxo do protótipo



O fluxo principal contempla:



1\. Tela inicial

2\. Tela de disciplinas

3\. Tela de atividades

4\. Tela de detalhes

5\. Tela de perfil



A navegação entre as telas foi configurada no modo \*\*Prototype do Figma\*\*, permitindo testar a interação entre os elementos.
