# dev-web-2026

\# 1ª Avaliação — Design System \& Protótipo



Projeto desenvolvido no Figma para a disciplina, com o objetivo de criar um \*\*Design System estruturado\*\* e um \*\*protótipo navegável\*\*, utilizando variáveis, componentes reutilizáveis e padrões de interface.



\## 🔗 Figma



\*\*Link público do projeto:\*\*

https://www.figma.com/design/J1EALLneDNDZ7lyRdGeWSn/Sem-t%25C3%ADtulo?node-id=0-1\&p=f\&t=viN0bwyOGvlKV0Kp-0



> O arquivo foi desenvolvido no Figma utilizando variáveis locais e componentes reutilizáveis para manter a consistência visual entre as telas.



\---



\## 🎨 Design System



O Design System foi estruturado com variáveis de \*\*cores\*\* e \*\*tipografia\*\*, permitindo sua reutilização durante a construção do protótipo.



\### Cores



Foram criadas as seguintes categorias de cores:



\* \*\*Primary\*\*

\* \*\*Secondary\*\*

\* \*\*Tertiary\*\*

\* \*\*Background\*\*

\* \*\*OnBackground\*\*

\* \*\*OnSurface\*\*



As cores \*\*OnSurface\*\* foram configuradas para os modos \*\*Light\*\* e \*\*Dark\*\*, permitindo sua utilização em diferentes contextos da interface.



\### Tipografia



A escala tipográfica contém:



\* \*\*Headline\*\*

\* \*\*Title\*\*

\* \*\*Subtitle\*\*

\* \*\*Body\*\*

\* \*\*Button\*\*



A nova categoria \*\*Title\*\* foi adicionada com suas respectivas especificações de:



\* Tamanho

\* Peso

\* Espaçamento



\---



\## 🧩 Componentes



Foram desenvolvidos componentes reutilizáveis no Figma para garantir consistência e facilitar a manutenção da interface.



\### Botões



Foram criados três tipos de botões:



\* \*\*Botão Primário\*\*

\* \*\*Botão Secundário\*\*

\* \*\*Botão Terciário\*\*



Os botões foram configurados como \*\*componentes reais do Figma\*\*, podendo ser reutilizados nas diferentes telas do protótipo.



\### AppBar



Também foi desenvolvido o componente \*\*AppBar\*\*, utilizado como elemento de navegação nas telas.



O AppBar possui:



\* Variante padrão

\* \*\*Variante Dark\*\*



O componente foi utilizado nas telas do protótipo para manter um padrão de navegação consistente.



\---



\## 📱 Protótipo Navegável



O projeto possui um fluxo de telas navegável desenvolvido no Figma.



As telas utilizam:



\* AppBar;

\* Variáveis de cores;

\* Variáveis tipográficas;

\* Componentes de botão;

\* Componentes reutilizáveis do Design System.



As interações foram configuradas no modo \*\*Prototype\*\* do Figma, permitindo navegar entre as telas e visualizar o fluxo da aplicação.
