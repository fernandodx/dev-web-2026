# Magnatas do Crime — Página com HTML & Bootstrap

Página web sobre a série **Magnatas do Crime**, feita com HTML semântico e Bootstrap 5 (via CDN).

## Estrutura
```
magnatas-do-crime/
├── index.html   (HTML + CSS no mesmo arquivo)
└── README.md
```

## Elementos utilizados
- **HTML semântico:** `<header>`, `<nav>`, `<main>`, `<section>`, `<article>` e `<footer>`.
- **Bootstrap via CDN:** grid responsivo (`container`, `row`, `col-*`) e classes utilitárias (`py-4`, `mb-5`, `text-center`, `bg-dark`, etc.).
- **Card:** personagens do elenco e temporadas exibidos em cards.
- **Breadcrumb:** navegação de contexto no topo (Início > Séries > Magnatas do Crime).
- **Carousel:** carrossel com 3 slides de destaques da série.
- **Conteúdo:** título, sinopse, elenco principal e imagens.
