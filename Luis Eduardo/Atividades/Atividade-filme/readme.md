# 🎬 Resgate 2 (Extraction 2) — Página de Filme

**2ª Avaliação — HTML & CSS**

Página web sobre o filme **Resgate 2** (2023), da Netflix, dirigido por **Sam Hargrave**
e estrelado por **Chris Hemsworth**.

## 📁 Estrutura do projeto

resgate2/
├── index.html
├── estilo.css
├── README.md
└── imagens/
    └── capa.jpg

## ✅ Conceitos aplicados

| Requisito | Como foi aplicado |
|-----------|-------------------|
| **HTML semântico** | `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<figure>`, `<footer>` |
| **CSS separado** | `estilo.css` vinculado ao `index.html` com `<link rel="stylesheet" href="estilo.css">` |
| **Variáveis CSS** | Cores, fontes e espaçamentos definidos em `:root` e usados com `var(--nome)` |
| **Layout** | **Flexbox** (menu, elenco, selos) e **Grid** (sinopse, ficha técnica, curiosidades) |
| **Responsividade** | `@media (max-width: 800px)`, `auto-fit`/`minmax` e `clamp()` |
| **Conteúdo** | Título, sinopse, elenco, diretor e imagem de capa |
