# dev-web-2026
Galeria Digital
Sobre o projeto

A Galeria Digital é um protótipo desenvolvido no Figma como parte da 1ª Avaliação de Design System.

O projeto apresenta uma interface para uma galeria de arte digital, permitindo a apresentação de uma artista e suas obras por meio de um fluxo navegável.

O desenvolvimento foi realizado aplicando conceitos de **Design System, variáveis, componentes, variantes e prototipação no Figma.

Objetivo

Criar um Design System estruturado e um protótipo navegável, utilizando variáveis e componentes reutilizáveis para manter a consistência visual entre as telas.

Design System
Cores

Foram criadas variáveis locais reutilizáveis para as cores do sistema:

- Primary
- Secondary
- Tertiary
- Background
- OnBackground
- OnSurface - Light
- OnSurface - Dark

As cores são utilizadas de forma consistente nos elementos da interface.

Tipografia

Foram criadas definições tipográficas para:

- Headline
- Subtitle
- Body
- Button

A tipografia Title possui definição própria de tamanho, peso e espaçamento, conforme os padrões propostos na atividade.

Componentes

Foram desenvolvidos componentes reutilizáveis no Figma:

Botões

- Botão Primário
- Botão Secundário
- Botão Terciário

Os botões foram criados como componentes reais do Figma, permitindo sua reutilização e padronização no projeto.

AppBar

Foi desenvolvido um componente AppBar, utilizado nas telas do protótipo.

Também foi criada uma variante Dark do AppBar, permitindo sua utilização em diferentes contextos visuais.


Protótipo

O protótipo possui navegação entre as telas utilizando os componentes e variáveis definidos no Design System.

Fluxo de navegação

Login -> Sobre mim -> Minhas obras

Telas
Login

Tela inicial de acesso à Galeria Digital.

Sobre mim

Apresenta as informações da artista Maria Antonieta, incluindo sua área de atuação, localização e uma breve descrição.

Minhas obras

Apresenta as obras da artista:

- Frutos da Primavera | 2026 - Pintura
- Pequenas Companhias | 2026 - Pintura

O protótipo utiliza o AppBar nas telas e os elementos desenvolvidos no Design System.
